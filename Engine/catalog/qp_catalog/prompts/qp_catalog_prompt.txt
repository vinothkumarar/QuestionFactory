QUESTION POSSIBILITY DEFINITION

A Question Possibility (QP) is an
academically distinct examinable possibility.

A QP represents:

WHAT can be asked.

A QP is NOT:

• A question
• An MCQ
• An archetype
• A solving method
• A trick
• A shortcut

--------------------------------------------------

GOOD EXAMPLES

Evaluate absolute value expression

Solve absolute value equation

Solve absolute value inequality

Determine range involving absolute value

Determine number of solutions of an
absolute value equation

--------------------------------------------------

BAD EXAMPLES

Solve |x-3| < 5

Find value of |2x+1|

If |x| = 5 find x

These are QUESTIONS,
not Question Possibilities.

DISCOVERY RULES

1. Discover ALL Question Possibilities.

2. Include:

   • Direct possibilities
   • Reverse possibilities
   • Application possibilities
   • Multi-step possibilities
   • Comparative possibilities
   • Analytical possibilities
   • JEE Main possibilities
   • JEE Advanced possibilities

3. Do NOT generate actual questions.

4. Do NOT generate archetypes.

5. Do NOT create duplicates.

6. Exhaustively enumerate the academic space.

7. Generate Question Possibilities ONLY for the
   supplied Concept.

8. Do NOT expand into neighboring concepts,
   derived concepts, advanced applications,
   later syllabus concepts, or concepts that
   require additional theory beyond the
   supplied Concept.

9. Every Question Possibility must be directly
   answerable using the supplied Concept as
   the primary knowledge requirement.

10. If a possibility primarily belongs to a
    different Concept, do NOT include it.

11. Prefer depth within the supplied Concept
    rather than breadth across related concepts.

12. Do NOT create Question Possibilities that
    primarily depend on knowledge that is
    outside the supplied Concept.

    If solving or answering the possibility
    requires another major Concept as the
    primary prerequisite, do NOT include it.

13. Exhaust the COMPLETE Question Possibility
    Space of the supplied Concept, but remain
    strictly inside Concept boundaries.

QUESTION POSSIBILITY DEFINITION RULES

14. A Question Possibility represents an
    academically distinct examinable outcome
    that can be assessed using the supplied
    Concept.

15. A Question Possibility describes
    WHAT is being assessed,
    not HOW it is solved.

16. Do NOT create separate Question
    Possibilities for:

    • Different formulas
    • Different equations
    • Different solution methods
    • Different computational techniques
    • Different named models
    • Different named derivations

17. Such variations belong to the
    Archetype layer, not the
    Question Possibility layer.

18. Multiple approaches that assess the
    same underlying learning outcome
    must be represented by a single
    Question Possibility.

19. Prefer learning outcomes over
    solution procedures.

20. A student who has mastered the
    supplied Concept should recognize
    the Question Possibility before
    selecting a solution method.
