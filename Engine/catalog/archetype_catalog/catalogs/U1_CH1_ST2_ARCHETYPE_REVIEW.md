# U1–CH1–ST2 Representative Archetype Qualification Pack

**Purpose:** Test the ten source QPs against concrete mathematical tasks before creating permanent archetype IDs.  
**Status:** Candidate mechanisms only; no approval or manufacturing authorization.

## Scope and notation

Use N = {1,2,3,...}, W = {0,1,2,...}, Z, Q, R\\Q and R. Use ⊂ for proper inclusion and ⊆ for inclusion allowing equality. All claims must be interpreted under these definitions.

Do not import divisibility, parity, prime-number properties, interval theory, polynomial roots, calculus, matrices, geometry, or general set-algebra identities. A task requiring one of those topics is out of scope for this ST2 review.

## Representative tasks and decisions

### Mechanism A — Verify or reject a proposed inclusion

**Source QPs:** QP001 Correct Inclusion Relation; QP002 Incorrect Inclusion Relation; QP010 only when diagram is merely another presentation.

**Representative task:** Which statement is necessarily true?
1. W ⊆ N
2. Z ⊆ W
3. N ⊆ Z
4. Q ⊆ Z

**Reasoning:** Use the definitions and exhibit a valid element to reject each false direction. N ⊆ Z is true.

**Qualification:** Foundation. This is a direct hierarchy check. It is useful prerequisite material, but not a distinct high-difficulty JEE archetype. Correct/incorrect polarity and diagram display do not create separate archetypes.

### Mechanism B — Infer a missing link in an inclusion chain

**Source QPs:** QP003 Complete Inclusion Chain; QP004 Missing Set Identification.

**Representative task:** Given N ⊆ A and A ⊆ Q, which relation must hold?

**Reasoning:** Apply transitivity of inclusion to infer N ⊆ Q. Do not infer the reverse relation.

**Qualification:** Foundation to moderate. This is the clearest reusable inference pattern in the source QPs. A missing symbol or missing intermediate set is a variation only when it preserves the same transitive reasoning.

### Mechanism C — Distinguish inclusion from proper inclusion

**Source QPs:** QP005 Proper Subset Identification; QP006 Superset Identification.

**Representative task:** Let A = N and B = W. Is A a proper subset of B? Is B a superset of A?

**Reasoning:** Every natural number is a whole number, and 0 ∈ W but 0 ∉ N. Therefore A ⊂ B and B ⊃ A.

**Qualification:** Foundation to moderate. The key distinction is proving strictness by finding an element in the larger set that is absent from the smaller. Subset/superset wording is not a separate mechanism.

### Mechanism D — Propagate element membership through inclusion

**Source QP:** QP007 Membership using Inclusion.

**Representative task:** If A ⊆ B and x ∈ A, what follows about x?

**Reasoning:** By the definition of subset, x ∈ B. The converse does not follow from the given information.

**Qualification:** Foundation. This is logically valid but close to the definition itself. Keep it as a short prerequisite assessment unless a source-faithful task adds genuine inference without importing another topic.

### Mechanism E — Evaluate a universal claim by constructing a counterexample

**Source QPs:** QP008 Set Relationship Statements; QP009 Counterexample to Inclusion.

**Representative task:** A student claims that every integer is a whole number. Disprove the claim with one valid counterexample.

**Reasoning:** -1 ∈ Z but -1 ∉ W. One counterexample is sufficient to refute the universal claim.

**Qualification:** Foundation to moderate. Statement evaluation and counterexample construction overlap when the task is to refute a universal inclusion. Do not duplicate the same reasoning under separate QP labels.
